# updatedonlinesikha14

New update page for Online Siksha.

## Local setup

1. Install dependencies:
   `npm install`
2. Start the app locally:
   `npm run dev`
3. Open the app in the browser at the local Vite address shown in the terminal.

## Project info

This project is a React + Vite front-end for the LPU online degrees and admissions portal, with a local Express server for development use.
